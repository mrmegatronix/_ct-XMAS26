# Social Club Xmas Party 2026 - Tiki Beach Holiday 🌺🍍🎄

Digital Signage Slideshow and Official A4 Printable Cocktail Menu for the Social Club Christmas Party on **Saturday Night, 12 December 2026** (the second Saturday night in December 2026).

## 🌴 Highlights & Features
- **1080p Digital Signage Display (`index.html`)**:
  - Optimized for 1920x1080 venue screens with zero text clipping and dynamic font auto-fit.
  - Digital clock with **blinking colons** meeting all digital signage specifications.
  - 7 Slides: Event Invitation, 4 Signature Cocktails, Island Luau Feast, Party Timeline, Best Dressed Awards, Photo Booth & QR Gallery, Live Party Countdown.
  - Ambient particle canvas with tiki embers, fireflies, and tropical sparkles.
- **Tiki Beach A4 Printable Cocktail Menu (`menu.html`)**:
  - Single-page A4 print layout (`@page { size: A4 portrait; margin: 0; }`).
  - Carved bamboo border, tiki totems, hibiscus blossoms, and 4 easy & fabulous cocktails (+ mocktail).
  - Quick bartender and volunteer batching tips.
- **Admin Control Panel (`admin.html`)**:
  - Real-time announcements ticker, date/time config, and cocktail management.
- **Mobile Remote (`remote.html`)**:
  - Touch-friendly venue pad for remote presentation control via BroadcastChannel API.

## ⌨️ Slideshow Keyboard Controls
- `ArrowLeft`: Previous Slide
- `ArrowRight`: Next Slide
- `ArrowUp`: Restart from Slide 1
- `ArrowDown`: Skip to Next Module
- `Space`: Pause / Resume Slide Progression
- `a` / `A`: Open Admin Panel
- `r` / `R`: Open Mobile Remote
- `m` / `M`: Open A4 Cocktail Menu
- `1` - `9`: Set slide display duration (10s to 90s)
- `0`: Lock / Freeze slide progression
